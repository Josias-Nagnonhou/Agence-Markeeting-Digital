## Footwik Pro

Le dossier [`footwik-pro`](./footwik-pro) contient l'application web
Footwik Pro : une plateforme d'analyse de matchs de football par
intelligence artificielle pour les parieurs sportifs francophones
d'Afrique et de la diaspora. Voir [`footwik-pro/README.md`](./footwik-pro/README.md)
pour la documentation complète et les instructions de démarrage.
